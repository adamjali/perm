The first days of October opened the data up and added the seasonal visas,
which share DOL's case counter with PERM.

## H-2A, H-2B and CW-1

DOL's case system answers H-2A applications and job orders, H-2B applications
and wage requests, and CW-1 applications from the same counter as PERM. They're
all looked up now: a case number shows DOL's live status, and once DOL
publishes the case, the decision, wage, workers, work period and worksite.

- [Seasonal cases](/seasonal-cases) lists them, with decisions per day for each
  visa.
- A pending application shows when DOL usually decides, measured from its own
  certifications.
- Every employer that files only these visas has a page of its own.

## Open data

[Open data](/open-data) offers two datasets as CSV and JSON under CC BY 4.0:
the visa bulletin archive since June 2005, cell by cell as printed, and every DOL
processing-times reading this site has kept.

## A free API and an MCP server

[Developers](/developers) documents a free JSON API, with keys from Settings,
and an MCP server that assistants such as Claude can call without a key. Both
answer from the same reads as the pages.

## Longer records

- The bulletin archive reaches June 2005, 237 bulletins.
- DOL's decisions per day reach October 2015.

## Smaller changes

- A daily pulse on [the homepage](/) and [decision activity](/perm-decision-activity):
  the newest day's decisions against the same weekday over the four weeks before.
- One breadcrumb bar on every public page, and every chart shows its figures on
  hover or tap.
- Settings and the emailed preference page list every email from one place.
